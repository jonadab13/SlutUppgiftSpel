# Score Tracker

## About The Project

Score Tracker is a simple backend API i made with Express.js and SQLite.  
it stores player scores in a database and allows users to create, read, update, and delete scores.

This was made as a rest API

---

## Features

- Get all scores
- Get one score by ID
- Create new scores
- Update scores
- Delete scores
- Search scores using query parameters

---

## Technologies Used

- Node.js
- Express.js
- SQLite

---

The project uses a SQLite database called:

scores.db
